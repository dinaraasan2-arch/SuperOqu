СУПЕР ОҚУ — Android проект (версия 0.2, прототип)

Это НАСТОЯЩИЙ проект Android-приложения на Java с обучением буквам, 6 мини-играми, сказками, сохранением прогресса и Android TTS (казахский язык).
APK в этой среде собрать не удалось: отсутствует Android SDK и нет доступа к сети для установки инструментов.

Сборка APK через GitHub (можно с Android-телефона):
1. Создайте ПУСТОЙ репозиторий на github.com.
2. Загрузите туда СОДЕРЖИМОЕ этого архива, включая скрытую папку .github/workflows.
   В мобильном интерфейсе удобно воспользоваться веб-режимом или приложением GitHub, загружая распакованные файлы.
3. Откройте вкладку Actions -> Build Android APK -> Run workflow.
4. После выполнения скачайте artifact SuperOqu-debug-apk, распакуйте, установите app-debug.apk на Android.

Требования: Android 7.0+, желательно установленный казахский голос в системе Android TTS. Женский голос и естественность звучания не гарантированы: для коммерческого качества нужны отдельные проверенные аудиозаписи от диктора или лицензируемый TTS движок.

Ограничения: это НЕ готовый к продаже продукт, а функциональная ранняя версия. Нужны тесты произношения с носителями, детское UX-тестирование, оригинальная графика, юридическая проверка контента, политика конфиденциальности. Не копируйте страницы и иллюстрации учебника в коммерческое приложение без проверки прав.
